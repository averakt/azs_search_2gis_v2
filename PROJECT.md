# Project: azs_search_2gis_v2

## Purpose

Проект разработки приложения поиска АЗС через 2GIS.


## Development Rules

Перед большими изменениями:

1. Провести анализ.
2. Описать архитектуру.
3. Определить затронутые компоненты.


## Workflow

Architecture:
GLM 5.2

Implementation:
Qwen 3.5 Plus

Testing:
DeepSeek V4 Flash Free

Review:
GLM 5.2


## Quality Requirements

Перед Pull Request:

- tests должны проходить
- lint должен проходить
- build должен проходить
- код должен пройти review
