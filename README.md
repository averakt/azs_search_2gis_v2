# azs_search_2gis_v2

Веб-приложение для поиска ближайших АЗС с наличием топлива, ценами и оценкой очереди. Данные предоставляются через API 2ГИС (benzin.2gis.ru).

## Возможности

- 🔍 Поиск по адресу (подсказки через OSM Nominatim + геокодирование 2ГИС)
- ⛽ Отображение АЗС с ценами и наличием топлива
- 📊 Оценка очереди (по данным пользовательских отчётов 2ГИС)
- 🗺️ Переключение провайдера: 2ГИС (с топливом) ↔ OSM (без топлива, fallback)
- 🔧 Фильтр по типу топлива (АИ-92/95/98/100, ДТ, Газ)
- 📏 Выбор радиуса поиска: 1/3/5/10 км
- 📱 Адаптивный дизайн

## Принцип поиска

### 1. Подсказки адреса (suggest)
При вводе адреса фронтенд отправляет запрос на бэкенд `/api/suggest`. Бэкенд обращается к **OSM Nominatim** (`nominatim.openstreetmap.org/search`) — бесплатному API для поиска по частичному совпадению. Ответ содержит до 5 вариантов с координатами. При клике на подсказку карта центрируется сразу, без дополнительного геокодирования.

### 2. Геокодирование (поиск по адресу)
При нажатии Enter или кнопки 🔍 вызывается бэкенд `/api/geocode`. Он использует **catalog.api.2gis.com/3.0/items/geocode** — официальный геокодер 2ГИС. Требует API-ключ. Если адрес не найден, возвращается 404 с сообщением «Адрес не найден».

### 3. Поиск АЗС с топливом и очередью
После выбора адреса бэкенд делает два последовательных запроса к публичному **benzin.api.2gis.ru** (без ключа):

1. **`/api/v1/stations/search?q=АЗС&minLat=...&maxLat=...&minLon=...&maxLon=...`** — поиск АЗС в bounding box (рассчитывается из заданного радиуса с учётом широты для коррекции долготы).
2. **`/api/v1/stations/by-ids?ids=...`** — получение детальной информации: статусы топлива (available/price), уровень очереди, лимиты.

**Данные о топливе:**
- `fuel_assortment` — ассортимент станции (AI_92, AI_95, AI_98, AI_100, DT, GAS)
- `fuel_statuses` — наличие каждого типа (`available: true/false/null`, где null — нет отчётов)
- `prices` — актуальные цены в рублях
- Типы маппятся в русские названия: AI_92 → АИ-92, DT → ДТ, GAS → Газ

**Данные об очереди:**
- `queue_level` — уровень очереди от API: `NONE`, `UP_TO_10`, `UP_TO_25`, `UP_TO_45`, `MORE_45`
- Маппится в: `none`, `small` (~10 мин), `medium` (~25 мин), `large` (~45 мин), `very_large` (~60 мин)
- Данные основаны на пользовательских отчётах в 2ГИС

**Координаты станций:** возвращаются исходные координаты от API 2ГИС (с ID вида `4504127920045992`).

### 4. Fallback на OSM
Если benzin.api.2gis.ru недоступен или возвращает ошибку, бэкенд автоматически переключается на **OSM Overpass API** (`overpass-api.de/api/interpreter`). Overpass ищет узлы и пути с тегом `amenity=fuel` в заданном радиусе. Данные о топливе и очереди в этом случае отсутствуют, ID станций имеют префикс `osm_*`.

### 5. Кэширование
Все запросы кэшируются в памяти на 10 минут (настраивается через `CACHE_TTL`). Ключ кэша строится по провайдеру, координатам, радиусу и фильтру топлива. Повторные запросы с теми же параметрами не ходят во внешние API.

## Быстрый старт

### Через Docker (рекомендуется)

1. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```

2. (Опционально) Добавьте API ключи в `.env`:
   - `TWOGIS_API_KEY` — ключ 2GIS API (партнёрский кабинет)
   - `YANDEX_API_KEY` — ключ Yandex API

3. Запустите:
   ```bash
   docker compose up --build
   ```

4. Откройте http://localhost:80

### Локальная разработка

#### Backend

```bash
cd backend
go mod download
go run ./cmd/server
```

Backend доступен на http://localhost:8080

#### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend доступен на http://localhost:5173

## API

### GET /api/health

Проверка работоспособности.

### GET /api/suggest?q=<query>&limit=<n>

Подсказки адреса при вводе (OSM Nominatim).

**Параметры:**
- `q` — поисковый запрос (частичное совпадение)
- `limit` — макс. количество результатов (по умолчанию 5)

**Ответ:** массив объектов с `lat`, `lon`, `label`.

### GET /api/geocode?q=<address>&provider=2gis|yandex

Геокодирование адреса.

**Ответ:**
```json
{
  "lat": 55.751244,
  "lon": 37.618423,
  "label": "Москва, Тверская улица, 1",
  "provider": "2gis"
}
```

### GET /api/stations?lat=<lat>&lon=<lon>&radius=<m>&fuel=<type>&provider=2gis|yandex

Поиск АЗС в радиусе.

**Параметры:**
- `lat`, `lon` — координаты центра поиска
- `radius` — радиус в метрах (по умолчанию 3000)
- `fuel` — тип топлива: `92`, `95`, `98`, `100`, `dt`, `gas`
- `provider` — провайдер данных

**Ответ:**
```json
{
  "stations": [
    {
      "id": "...",
      "name": "...",
      "brand": "Лукойл",
      "address": "Москва, ул. Примерная, 1",
      "lat": 55.75,
      "lon": 37.61,
      "distance": 250,
      "fuels": [
        {"type": "АИ-95", "avail": "yes", "price": 52.50, "currency": "RUB"}
      ],
      "queue": {"level": "small", "est_wait_min": 10},
      "limits": {"max_liters": 50, "can_jerrycan": true},
      "updated_at": "2026-07-30T12:00:00Z",
      "source": "2gis-benzin"
    }
  ]
}
```

## Конфигурация

Переменные окружения (`.env`):

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `8080` | Порт backend |
| `TWOGIS_API_KEY` | | Ключ 2GIS API |
| `YANDEX_API_KEY` | | Ключ Yandex API |
| `BENZIN_BASE_URL` | `https://benzin.api.2gis.ru` | URL API 2ГИС Бензин |
| `PASSEPARTOUT_URL` | `https://passepartout.2gis.com` | URL авторизации |
| `CACHE_TTL` | `10m` | Время жизни кэша |
| `HTTP_TIMEOUT` | `10s` | Таймаут HTTP запросов |
| `DEFAULT_RADIUS` | `3000` | Радиус поиска по умолчанию (м) |
| `ENABLE_HEADLESS_FALLBACK` | `false` | Включить headless-фолбэк |
| `LOG_LEVEL` | `info` | Уровень логирования |

## Headless Fallback

Если прямой запрос к `benzin.api.2gis.ru` не работает (токен origin-bound), можно включить headless-фолбэк:

```env
ENABLE_HEADLESS_FALLBACK=true
```

⚠️ **Внимание:** Headless режим требует Chromium в Docker-образе и увеличивает время обработки запроса.

## Ограничения и отказоустойчивость

- При недоступности `benzin.api.2gis.ru` приложение падает на OSM Overpass — АЗС находятся, но без цен и очередей
- Кэш TTL ~10 минут снижает нагрузку на API
- Singleflight предотвращает дублирование одинаковых запросов
- Bounding box для поиска АЗС рассчитывается из радиуса с учётом широты (cos-коррекция долготы), что обеспечивает равномерный круг поиска на всех широтах
- Подсказки (suggest) через OSM Nominatim могут находить адреса из разных стран/регионов — для точного поиска указывайте город (например, «Москва, Кравченко»)
